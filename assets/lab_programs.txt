18. Registration + Login validation.
Register: username minimum 6 characters; password minimum 8 characters; mobile 10 digits; email format; DOB no validation; radio and checkbox checked → “Thank you for registration” → login page.
Login: username/email + password → “Welcome” → dashboard
register.html
	<!DOCTYPE html>
<html>
<body>
    <h2>Registration</h2>
    <form onsubmit="return validate()">
        Username: <input id="username"><br><br>
        Password: <input type="password" id="password"><br><br>
        Mobile: <input id="mobile"><br><br>
        Email: <input id="email" type="email"><br><br>
        DOB: <input type="date" id="dob"><br><br>
        Gender:
        <input type="radio" id="male" name="gender">Male
        <input type="radio" id="female" name="gender">Female<br><br>
        <input type="checkbox" id="terms">I accept terms<br><br>
        <input type="submit" value="Register">
    </form>


    <script>
        function validate() {
            if (!/^.{6,}$/.test(username.value)) {
                alert("Username: minimum 6 characters");
                return false;
            }
            if (!/^.{8,}$/.test(password.value)) {
                alert("Password: minimum 8 characters");
                return false;
            }
            if (!/^\d{10}$/.test(mobile.value)) {
                alert("Mobile: 10 digits only");
                return false;
            }
            if (!/^\S+@\S+\.\S+$/.test(email.value)) {
                alert("Enter a valid email");
                return false;
            }
            if (!male.checked && !female.checked) {
                alert("Select gender");
                return false;
            }
            if (!terms.checked) {
                alert("Accept the terms");
                return false;
            }
            alert("Thank you for registration");
            return false;
        }
    </script>
</body>
</html>

8. JDBC: DDL and CRUD
26. Write a Java program to apply all DDL commands on a database
DDL.java
	import java.sql.*;


public class DDL {
    public static void main(String[] args) throws Exception {
        String url = "jdbc:mysql://localhost:3306/studentdb";
        Connection con = DriverManager.getConnection(url, "root", "");
        Statement st = con.createStatement();


        st.executeUpdate("CREATE TABLE student(id INT, name VARCHAR(20))");
        System.out.println("Table created");


        st.executeUpdate("ALTER TABLE student ADD age INT");
        System.out.println("Table altered");


        st.executeUpdate("RENAME TABLE student TO stud");
        System.out.println("Table renamed");


        st.executeUpdate("TRUNCATE TABLE stud");
        System.out.println("Table truncated");


        st.executeUpdate("DROP TABLE stud");
        System.out.println("Table dropped");


        con.close();
    }
}
	

Steps
1. In MySQL: CREATE DATABASE studentdb;
1. Put mysql-connector-j.jar in the same folder as the .java file
1. Compile: javac DDL.java
1. Run: java -cp ".;mysql-connector-j.jar" DDL
1. Use your own MySQL password in place of ""
27. Java program to perform CRUD operations (Create, Read, Update, Delete)
CRUD.java
	import java.sql.*;


public class CRUD {
    public static void main(String[] args) throws Exception {
        String url = "jdbc:mysql://localhost:3306/studentdb";
        Connection con = DriverManager.getConnection(url, "root", "");
        Statement st = con.createStatement();
        st.executeUpdate("CREATE TABLE IF NOT EXISTS student(id INT, name VARCHAR(20))");


        st.executeUpdate("INSERT INTO student VALUES(1, 'Ravi'), (2, 'Teja')");
        System.out.println("Inserted");


        st.executeUpdate("UPDATE student SET name = 'Kiran' WHERE id = 1");
        System.out.println("Updated");


        st.executeUpdate("DELETE FROM student WHERE id = 2");
        System.out.println("Deleted");


        ResultSet rs = st.executeQuery("SELECT * FROM student");
        while (rs.next()) {
            System.out.println(rs.getInt(1) + " " + rs.getString(2));
        }


        con.close();
    }
}

30. Promises
promise1.js — even or odd
	function check(n) {
    return new Promise((resolve, reject) => {
        if (n % 2 == 0) resolve("Even");
        else reject("Odd");
    });
}


check(10)
    .then(msg => console.log(msg))
    .catch(err => console.log(err));
	

promise2.js — login system
	function login(user) {
    return new Promise((resolve, reject) => {
        if (user == "admin") resolve("Login success");
        else reject("Login failed");
    });
}


login("admin")
    .then(msg => console.log(msg))
    .catch(err => console.log(err));
	

promise3.js — same as promise1 using async/await
	function check(n) {
    return new Promise((resolve, reject) => {
        if (n % 2 == 0) resolve("Even");
        else reject("Odd");
    });
}


async function run() {
    try {
        console.log(await check(7));
    } catch (err) {
        console.log(err);
    }
}


run();
	

Note: resolve → goes to .then(); reject → goes to .catch().
